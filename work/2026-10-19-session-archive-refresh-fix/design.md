# Archive and index repair brief

Lead owns design and application edits; there is no retained implementation
team. Work at xhigh effort because lifecycle changes affect persistent recovery.

## Lifecycle

Treat prior tracking commits as bookkeeping, not local-first archival eligibility.
Skip validate_tracking_committed! for fresh local-first archives and finalization
under a local tracking journal. Preserve the prerequisite for synchronous legacy
journals and direct legacy finalize calls. Automatic complete/merged/empty tiers
keep exact existing eligibility and sealed mode; do not convert them to explicit
archive or weaken clean/publication/merge/idle/hold checks. Validate actual local
tracking and ownership as before. Keep formats and async sync/restore semantics.

## Portal

Keep keyed rows by operation receipt/identity, with current data used by action
handlers. Repeated identical displayed content causes no child/text replacement
or DOM move. Update actual elapsed progress without rebuilding error rows.
Session cards retain existing identity, change only changed text/attributes, and
move only when ordering or active/archive membership actually changes. Preserve
in-flight control state, focus, scroll, selection and retry/dismiss behavior.
No refresh pause or new polling policy. No new public interface.

## Acceptance and rollout

Prove local-first uncommitted/partially committed archives across policies,
retry, failed/successful Git sync and revival. Retain negative policy and legacy
tests. Prove browser Range text and anchor/focus identity through full and
progress refreshes, neighboring updates, and updated actions. Use real browser
fixtures and isolated workspaces; never adjust live auto-archive timestamps.
Run focused checks before final committed review, longer packaged lifecycle and
browser verification afterward. Publish runtime and select one final pin stream
per consumer. Use matching configuration/system then application profile through
coordinator; preserve reservations and recover forward. Retry only the user's
failed target via ordinary retained portal operation; verify sync and retirement.
