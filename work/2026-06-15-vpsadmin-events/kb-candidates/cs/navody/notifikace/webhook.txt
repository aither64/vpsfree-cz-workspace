====== Odeslání změn prostředků VPS na webhook ======

Tento příklad posílá podepsaný JSON na HTTPS endpoint při každé události
''vps.resources_changed''. Formát podporuje jednotlivé i seskupené notifikace.

Nejprve si přečtěte [[navody:notifikace|přehled notifikačního systému]].

===== Krok 1: Připravte jednoduchý přijímací server =====

Následující kód uložte jako ''webhook.py''. Ověří podpis HMAC z přesného těla
požadavku, porovná ID doručení a vypíše všechny přijaté události:

<code python>
import hashlib
import hmac
import json
import os
from http.server import BaseHTTPRequestHandler, HTTPServer

SECRET = os.environ["VPSADMIN_WEBHOOK_SECRET"].encode()


class Handler(BaseHTTPRequestHandler):
    def do_POST(self):
        length = int(self.headers.get("Content-Length", "0"))
        body = self.rfile.read(length)
        expected = "sha256=" + hmac.new(
            SECRET, body, hashlib.sha256
        ).hexdigest()
        received = self.headers.get("X-VpsAdmin-Signature-256", "")

        if not hmac.compare_digest(received, expected):
            self.send_response(401)
            self.end_headers()
            return

        data = json.loads(body)
        delivery_id = str(data["delivery"]["id"])
        if self.headers.get("X-VpsAdmin-Delivery") != delivery_id:
            self.send_response(400)
            self.end_headers()
            return

        print("group:", data["group"])
        for event in data["events"]:
            print("event:", event["id"], event["type"], event["fields"])

        self.send_response(204)
        self.end_headers()


HTTPServer(("127.0.0.1", 8080), Handler).serve_forever()
</code>

Spusťte jej za veřejnou HTTPS reverzní proxy:

<code>
export VPSADMIN_WEBHOOK_SECRET="$(openssl rand -hex 32)"
printf '%s\n' "$VPSADMIN_WEBHOOK_SECRET"
python3 webhook.py
</code>

Tajemství bezpečně uložte. Server naslouchá pouze na ''127.0.0.1:8080''; URL
nastavená ve vpsAdminu musí být veřejná a používat HTTPS.

===== Krok 2: Vytvořte webhookový cíl =====

V <vpsadmin-nav id="notifications.target-form.open">**Notifikace →
Cíle**</vpsadmin-nav> přidejte typ **Webhook**. Zadejte veřejnou URL, například
''https://events.example.net/vpsadmin'', a stejné tajemství. vpsAdmin odmítá
privátní, lokální, link-local a jiné nebezpečné cílové adresy.

{{:cs:screenshots:vpsadmin:notifications:example-webhook-target.png?900|Webhookový cíl s veřejnou URL a HMAC tajemstvím}}

===== Krok 3: Vytvořte příjemce =====

V <vpsadmin-nav id="notifications.receivers.open">**Notifikace →
Příjemci**</vpsadmin-nav> vytvořte **Webhook změn prostředků** a připojte k
němu nový webhookový cíl.

{{:cs:screenshots:vpsadmin:notifications:example-webhook.png?900|Webhookový cíl připojený k příjemci}}

===== Krok 4: Vytvořte routu =====

V <vpsadmin-nav id="notifications.routes.open">**Notifikace →
Routy**</vpsadmin-nav> přidejte:

^ Pole ^ Hodnota ^
| Název | ''Webhook změn prostředků VPS'' |
| Typ události | ''vps.resources_changed'' |
| Příjemce | Webhook změn prostředků |
| Povoleno | ano |
| Pokračovat | ano |

{{:cs:screenshots:vpsadmin:notifications:example-webhook-route.png?900|Webhooková routa pro změny prostředků VPS}}

===== Krok 5: Ověřte webhook =====

Dočasně routu přesuňte jako první a vypněte **Pokračovat**. Syntetická událost
se tak nedostane k výchozím šablonám, které potřebují reálnou VPS. Vytvořte
testovací událost ''vps.resources_changed'':

<code json>
{
  "vps_id": 123,
  "vps_hostname": "example-vps",
  "cpu": 4,
  "cpu_limit": 400,
  "memory": 8192,
  "swap": 2048,
  "reason": "Memory upgrade"
}
</code>

Server přijme ''Content-Type: application/json'', ''User-Agent: vpsAdmin
notification dispatcher'', ''X-VpsAdmin-Delivery'' a
''X-VpsAdmin-Signature-256''. U doručení jediné události je přítomna také
hlavička ''X-VpsAdmin-Event''. Seskupený požadavek má místo ní
''X-VpsAdmin-Group'' a v poli ''events'' může obsahovat více událostí.

Odpovídající routu zkontrolujte v
<vpsadmin-nav id="notifications.event-route-matches.open">**Notifikace →
Události → detail události**</vpsadmin-nav> a poté znovu zapněte
**Pokračovat**.

{{:cs:screenshots:vpsadmin:notifications:example-webhook-result.png?900|Test změny prostředků zastavený webhookovou routou}}

===== Co server přijme =====

ID a čas v tomto zkráceném příkladu jsou pouze ilustrační:

<code json>
{
  "version": 1,
  "group": {
    "grouped": false,
    "key": null,
    "labels": {},
    "event_count": 1,
    "truncated_count": 0
  },
  "events": [
    {
      "id": 48123,
      "type": "vps.resources_changed",
      "category": "vps",
      "severity": "info",
      "subject": "VPS resources changed",
      "summary": null,
      "payload": {
        "vps_id": 123,
        "memory": 8192
      },
      "fields": {
        "vps_id": 123,
        "vps_hostname": "example-vps"
      },
      "ip_addr": null,
      "source": {
        "class": null,
        "id": null
      },
      "user": {
        "id": 42,
        "login": "example"
      },
      "vps": null,
      "created_at": "2026-07-25T12:34:56Z"
    }
  ],
  "delivery": {
    "id": 91234,
    "action": "webhook",
    "route": {
      "id": 17,
      "label": "VPS resource-change webhook",
      "matcher_summary": "vps.resources_changed"
    },
    "receiver": {
      "id": 8,
      "label": "Resource-change webhook"
    },
    "notification_target": {
      "id": 14,
      "label": "Resource changes",
      "display_target": "https://events.example.net/vpsadmin"
    },
    "receiver_target": {
      "id": 21
    }
  }
}
</code>

Podpis je HMAC-SHA256 z nezměněných bajtů těla a má tvar
''sha256=<HMAC>''. Libovolná odpověď ''2xx'' znamená úspěch. Neúspěšné
doručení se může opakovat, proto je zpracovávejte idempotentně podle podepsané
hodnoty ''delivery.id'' v těle. Hlavička ''X-VpsAdmin-Delivery'' není sama
podepsaná; příklad ji přijme pouze při shodě s ''delivery.id''.
