NAME
    build - Build target systems

SYNOPSIS

    confctl [global options] build [command options] [machine-pattern]

COMMAND OPTIONS
    -a, --attr=arg        - Filter by attribute (may be used more than once,
                            default: none)
    --cores=number        - Number of CPU cores to be used (see nix-build)
                            (default: none)
    -j, --max-jobs=number - Maximum number of build jobs (see nix-build)
                            (default: none)
    --[no-]show-trace     - Enable traces in Nix
    -t, --tag=arg         - Filter by tag (may be used more than once, default:
                            none)
    -y, --[no-]yes        - Assume the answer to confirmations is yes
