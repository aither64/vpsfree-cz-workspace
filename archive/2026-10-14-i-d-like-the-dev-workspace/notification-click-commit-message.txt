portal: focus existing notification tabs without reloading

Focus a matching same-origin session view directly, preferring the target
member when several views exist. Treat a single optional final slash as
the same session while keeping home and other session paths distinct.

Retain the current view and unsent draft instead of awaiting navigation
before focus. A failed focus must not open a duplicate tab. When no tab
matches, preserve canonical authenticated navigation and attention identity.
No worker acknowledgement, storage or protocol change is introduced.
