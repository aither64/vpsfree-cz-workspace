# Consistent close controls

The retry × now matches the existing message-receipt ×. These actual-page captures show both controls together. They use the same font, 17.6px glyph size, normal weight and resting/hover/focus colors. The retry control retains a larger clickable area.

Independent source review and the desktop/mobile browser comparison passed. This candidate is not deployed. The portal development guidance now requires consistency for all repeated controls.
