## Reusable send and recovery contract

Source paths in this section are relative to codex-web.

- `codex/client.go:5277–5315`: `SendWithOptions` holds the per-thread update lock,
  looks up the exact attempt and reconciles existing accepted/submitting or

- `5319–5337`: loads the exact thread, observes the active turn and records a

- `5340–5349`: atomic admission claims the durable attempt before the mutation

- `5383–5403`: a busy thread receives `turn/steer` with `expectedTurnId` and

## Retry hazards to retain in the proposal

1. **Stable identity binds content and options.**
   `client.go:2800–2807,2827–2854` rejects reuse of an ID with different text,
   action context or options. Persist the rendered outcome and original options,
   not a new timestamp/status rendering on each retry. The ordinary team context
   contains sender/recipient; an operation context needs its own exact event
   identity, including run/attempt/outcome.
2. **Native client IDs do not deduplicate.**
   `docs/submission-storage.md:14–30` describes the prepared/submitting boundary.
   The library ledger supplies suppression. Lost reply/history absence must not
   cause a new native send or a replacement ID. Reuse the configured persistent
   ledger and resolve the original uncertain attempt.
3. **Cancellation is not proof of non-delivery.**
   `client.go:5352–5381` restores safe unwritten refusals but reconciles after a
   possible write. `UnknownSendOutcomeError` must remain unresolved; only proven
   `MessageNotSentError` permits retry as unsent. Distinguish observer transport
   reconnection from command re-execution.
4. **Package/settings changes can invalidate a retry.**
   Reporting dispatch selects the current profile. The guide at
   `docs/workspace-portal.md:1605–1617` warns that an earlier team message ID may
   refuse if a package switch changes retained text/tool options. A completion
   adapter must preserve original input and reconcile it, not silently regenerate
   a different request under the old ID.
5. **Active-turn races remain explicit.**
   A prepared start/steer mismatch refuses at `client.go:5327–5328`; steering
   targets the observed turn. Direct native writers bypass application admission.
   Existing managed locking is needed around lifecycle/ownership checks and
   dispatch. A delivery receipt proves accepted input, not that the model
   completed the resulting work.
6. **Library sends do not own session lifecycle.**
   `SendWithOptions` can resume a destination. The operation adapter must check
   the current exact session/root and stop/archive/revocation boundaries under
   its ordinary runtime fence before granting that action. A queued or delayed
   completion must not reactivate retired or replaced ownership.
