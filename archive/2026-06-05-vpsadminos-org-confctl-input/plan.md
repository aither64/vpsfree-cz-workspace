# Update vpsadminos.org confctl input

## Goal

Update the `confctl` flake input in `vpsadminos-org-configuration` after the
NixOS 26.05 upgrade, keeping the tool bump separate and generated by
`confctl`.

## Affected Repository

- `vpsadminos-org-configuration`

## Approach

- Start from current `origin/master`.
- Use the repository's Nix development shell.
- Run `confctl inputs update --commit --no-changelog --no-editor confctl`.
- Validate inventory and build with the updated `confctl`.
- Merge to `master` by fast-forward from a temporary worktree and push.

## Compatibility

This changes the deployment tool input used by the configuration shell and
metadata generation. It does not change service configuration, persisted state,
database schemas, machine protocols, or vpsAdminOS node runtime behavior by
itself. The validation build confirms that generated NixOS/vpsAdminOS
configuration still evaluates with the updated tool.

Rollback is the previous `master` revision, which restores the former
`confctl` input in `flake.lock`.
