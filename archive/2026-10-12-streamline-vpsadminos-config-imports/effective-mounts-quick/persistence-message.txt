os: expose persisted allocation maps before legacy users (v8)

LXC supplies proc before init, so NixOS can skip its early mount path.
Activation then allocates accounts before saved UID/GID maps become visible.
A later bind exposes intact maps while passwd/group already contain new IDs,
leaving persisted numeric ownership disconnected from the live accounts.

Select effective non-root early mounts covering allocation state or logs,
including ancestor persistence and direct filesystem declarations. Prepare
missing directory-bind sources at their existing upstream callback position
and make legacy users depend on specialfs. Use the existing fsBefore relation
only to identify required predecessors; upstream owns all order and cycles.
Check required mount/remount results and bind identity, and explicitly exit
activation before allocation on failure. Unrelated callbacks retain their
existing behavior. Non-bind devices are not treated as directory sources.

Preserve configured tuples, matching live binds and existing metadata. Missing
selected sources receive root/0755 defaults; custom owner and mode require
pre-provisioning. Keep root-backed layouts, dry activation, alternative account
backends, guest specialfs overrides and standalone raw-file use. This changes
no account algorithm, stateVersion or persisted format and requires no host
coordination. Existing drift needs separate recovery; rollback can restore
the old ordering defect.

Add three-release evaluation and generated shell checks plus twelve registered
runtime variants for adoption, ancestors, direct binds and fresh allocation.
Private-namespace controls retain complete activation and the real allocator;
negative cases compare saved accounts/maps/data and refuse before allocation.
Provide bounded failure-only guest diagnostics and native private-store setup.
Three-release evaluation, generated shell checks, actual script syntax,
templates, documentation and declared hooks passed. Exact-head runtime evidence
is retained separately; prior eight-case/image acceptance applies only to its
recorded source.
