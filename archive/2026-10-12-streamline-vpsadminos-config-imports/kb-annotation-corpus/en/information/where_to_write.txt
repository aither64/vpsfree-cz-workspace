====== Where to write? ======
This is a guide for our [[communication|communication channels]].

===== Support =====
  * payment problems
  * VPS failing to boot
  * connection problems
  * problems with vpsAdmin
  * other problems that require the action of an admin
  * read [[support|how to write to our support]]
  * -> [[mailto:support@vpsfree.org|support@vpsfree.org]]

===== Discourse =====
  * questions about software / service configuration
  * solution recommendations (should I use Apache or Nginx?)
  * other community-related matters, such as meetups, etc.
  * -> [[https://discourse.vpsfree.cz/t/welcome-to-vpsfree-cz-discourse/5|Discourse]] or [[chat|IRC / Matrix]]
