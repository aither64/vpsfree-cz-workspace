NAME
    deploy - Deploy target systems

SYNOPSIS

    confctl [global options] deploy [command options] [machine-pattern [switch-action]]

COMMAND OPTIONS
    -a, --attr=arg            - Filter by attribute (may be used more than once,
                                default: none)
    --copy-only               - Do not activate copied closures
    --cores=number            - Number of CPU cores to be used (see nix-build)
                                (default: none)
    --disable-auto-rollback   - Disable auto-rollback
    --[no-]dry-activate-first - Try to dry-activate before the real switch
    --enable-auto-rollback    - Enable auto-rollback
    -g, --generation=arg      - Deploy selected generation (default: none)
    --[no-]health-checks      - Toggle health checks (default: enabled)
    -i, --[no-]interactive    - Ask for confirmation before activation
    -j, --max-jobs=number     - Maximum number of build jobs (see nix-build)
                                (default: none)
    --[no-]keep-going         - Do not abourt on failed health checks
    --max-concurrent-copy=n   - Max number of concurrent nix-copy-closure
                                processes (default: 5)
    --[no-]one-by-one         - Copy and deploy machines one by one
    --[no-]reboot             - Reboot target systems after deployment
    --[no-]show-trace         - Enable traces in Nix
    -t, --tag=arg             - Filter by tag (may be used more than once,
                                default: none)
    --wait-online=arg         - Wait for the machine to boot (default: 600)
    -y, --[no-]yes            - Assume the answer to confirmations is yes
