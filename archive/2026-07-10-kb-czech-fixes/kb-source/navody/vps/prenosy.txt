====== Datové přenosy ======

===== Měsíční přehledy =====

V menu Networking -> List monthly traffic se můžeme podívat na měsíční
přehledy přenesených dat. 

{{:navody:vps:datove_prenosy.png?300|}}

Ve výchozím stavu se zobrazí přenosy všech VPS za aktuální měsíc.
===== Real-time monitor přenosů =====

vpsAdmin měří přenesené data co 10 sekund a z toho počítá průměr za sekundu,
zobrazit si je můžeme buď v Networking -> Live monitor a nebo přes
[[navody:vps:api|vpsfreectl]].

==== Monitor v CLI ====
[[navody:vps:api|vpsfreectl]] obsahuje příkaz ''network top'', který spustí
TUI aplikaci podobnou iftop-u.

<code>
$ vpsfreectl network top --help
...
    -L, --list-parameters            List output parameters
    -o, --output PARAMETERS          Parameters to display, separated by a comma
...
Command options:
        --unit UNIT                  Select data unit (bytes or bits)
        --limit LIMIT                Number of IP addresses to monitor
        --user ID                    Filter network interfaces by user
        --environment ID             Filter network interfaces by environment
        --location ID                Filter network interfaces by location
        --node ID                    Filter network interfaces by node
        --vps ID                     Filter network interfaces by vps
        --network-interface ID       Filter network interfaces by network_interface
    -h, --help                       Show this message
</code>

{{ :navody:vps:net_monitor_cli.png?600 |}}

Program se dá ovládat pomocí šipek. Šipky doleva a doprava mění sloupec, podle
kterého jsou přenosy seřazeny. Šipky nahoru a dolů pak mění směr řazení, tzn.
vzestupně a sestupně. Program se ukončuje klávesou ''q''.

Přepínače kromě ''-o'' a ''-L'' se musí od argumentů vpsfreectl oddělit dvěmi
pomlčkami ''%%--%%''. Přepínačem ''%%--unit%%'' si můžeme vybrat, zda bude
program ukazovat přenosy v bajtech za sekundu nebo bitech za sekundu (výchozí
nastavení).

Příklady:

<code>
$ vpsfreectl network top -- --unit bytes

$ vpsfreectl network top -- --vps 1234
</code>
