  authorization and packaging examples and every new performance spec. It
  requires `make doc` first. The prepared JS build, declarations, TypeScript
  compiler and Node typings supply the existing dynamic documentation checks.

  `cd servers/ruby && bundle exec rspec spec/performance`. The full server command
  already includes that entire directory, including real worker/CLI controls;
  do not repeat the target after a successful full server run.

  Makefile's separate Rust gem home/path and cleared Bundler runtime variables.
  Its formatter is supplied by the top-level Nix shell. It does not run Cargo.

  accessible-tab checks, which are not RSpec examples. It reads checked-in assets

  server's client-example/documentation subset. It adds no missing coverage to

  phase-one campaign is retained evidence, not another required repeat here.
